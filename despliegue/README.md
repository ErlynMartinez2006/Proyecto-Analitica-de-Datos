# Despliegue

Interfaz para probar el modelo final (por ejemplo, con Streamlit o Dash):
el usuario ingresa los datos del colegio y la familia y recibe el puntaje global estimado.

La interfaz debe cargar el modelo guardado en `modelamientos/` y usar las funciones de `src/`
para aplicar la misma imputación y el mismo escalado del entrenamiento.
